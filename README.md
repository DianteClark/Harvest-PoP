# Harvest Pop

A free, cartoony fruit-and-veggie match-3 game with an idle farm, bosses, pets, seasons and power-ups. Built for phones.

**Play:** https://dianteclark.github.io/Harvest-PoP/

Everything is in one file, `index.html`. Progress saves in your browser on the device you play on.


## Harvest Pop 2.0
Restore Harvest Hollow: 150 levels across 5 areas, villagers, a garden, a kitchen and new power-ups. The original game is still playable at [classic/](classic/).
